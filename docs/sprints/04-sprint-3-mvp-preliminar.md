## O que é o MVP?

> **MVP (Produto Mínimo Viável):** versão mais básica e funcional do produto que pode ser lançada. Objetivo: testar rapidamente hipóteses com o menor esforço possível.

Benefícios do MVP:
- Reduz riscos do projeto
- Aumenta a probabilidade de sucesso
- Evita desperdícios — aprimora com base em dados reais
- Permite desenvolvimento iterativo com feedback de usuários
